# Customer Shopping Behavior Analysis

## 📌 Overview

This project is an **end-to-end Data Analytics project** focused on understanding customer shopping behavior and identifying meaningful business insights from retail customer data.

The project follows a practical analytics workflow:

**Raw Data → Python Data Cleaning & EDA → PostgreSQL SQL Analysis → Power BI Dashboard → Business Insights**

The analysis uses customer shopping data containing information such as age, gender, category, purchase amount, review rating, subscription status, shipping type, discounts, payment method, and previous purchases.

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Understand sales and revenue patterns across product categories.
* Compare customer behavior based on age and gender.
* Analyze subscription status and customer engagement.
* Identify products and categories with strong sales and revenue.
* Perform business-oriented analysis using SQL.
* Build an interactive Power BI dashboard for decision-making.

---

## 🐍 1. Python — Data Cleaning & EDA

Python was used as the first stage of the data analytics workflow.

### Libraries Used

* Pandas
* NumPy
* Matplotlib

### Tasks Performed

* Loaded the raw CSV dataset using Pandas.
* Inspected the dataset using `head()`, `info()`, and column analysis.
* Checked for missing values using `isnull().sum()`.
* Handled missing review ratings using **category-wise median imputation**.
* Removed unnecessary columns such as `promo_code_used` where appropriate.
* Standardized column names into lowercase and snake_case format.
* Renamed columns such as `purchase_amount_(usd)` to `purchase_amount`.
* Created/used customer age groups for further analysis.
* Performed exploratory analysis to understand customer purchasing patterns.
* Prepared the cleaned dataset for database analysis.

---

## 🗄️ 2. PostgreSQL — SQL Business Analysis

The cleaned dataset was loaded into **PostgreSQL** for structured querying and business analysis.

### Tools Used

* PostgreSQL
* pgAdmin
* SQLAlchemy
* Psycopg2

### SQL Analysis Performed

The project includes business-oriented SQL queries such as:

* Total revenue generated by male vs. female customers.
* Customers who used discounts but spent more than the average purchase amount.
* Top 5 products based on average review rating.
* Revenue and sales analysis by product category.
* Customer purchasing behavior and demographic analysis.
* Aggregation and comparison using `GROUP BY`, `SUM()`, `AVG()`, and filtering conditions.

### Example Business Question

> Which customers used a discount but still spent more than the average purchase amount?

This type of analysis helps identify customers who remain valuable even when discounts are applied.
